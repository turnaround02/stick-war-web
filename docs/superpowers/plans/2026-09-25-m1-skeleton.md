# M1 骨架 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 搭起 Phaser 4 + Vite + TypeScript 项目骨架，建立 `src/sim/` 纯逻辑核心的边界与类型，跑通固定 30Hz 逻辑帧 + 渲染插值管线，并在屏幕上画出一个站在地面线上的静态火柴人。

**Architecture:** 世界状态由 `src/sim/` 中的纯 TypeScript 对象持有，以固定 30Hz 整数 tick 步进，不 import 任何渲染库。`src/render/` 中的 Phaser 场景用累加器驱动 tick，每渲染帧读取 sim 状态并用插值系数平滑位置。两者之间只有「只读状态」和「指令数组」两个接触面。

**Tech Stack:** Phaser 4.2.1 / Vite ^6.3.1 / TypeScript ^5.7.2 / Vitest ^3 / ESLint ^9 (flat config) + typescript-eslint ^8 / npm

**Spec:** `docs/superpowers/specs/2026-09-25-stick-war-web-design.md`

## Global Constraints

以下约束逐字取自 spec，**每个任务都隐含包含本节**。

- 引擎 **Phaser 4.2.1**（不用 Phaser 3）
- Vite **^6.3.1** / TypeScript **^5.7.2** / Vitest **^3**（不升大版本；Vitest 5 要求 Vite 8）
- 包管理器 **npm**（环境未装 pnpm）
- `phaser` 包自带 TS 类型，**禁止**安装 `@types/phaser`
- 逻辑帧率固定 **30 Hz**，所有计时器为**整数 tick**
- 数据表用**秒**书写，加载时用 `Math.round(seconds * 30)` 转换**一次**
- `src/sim/**` **禁止** import `phaser`，也禁止 import `render/`、`input/`、`i18n/`
- sim 内**禁止** `Math.random()`、`Date.now()`、`performance.now()`
- 代码标识符与注释用**英文**；UI 文案用**中文**并走 i18n 键
- 世界宽度 **3000 px**；人口上限每方 **60**；同屏单位上限 **120**
- Vite `base` 必须是 **`/stick-war-web/`**
- **Phaser 4 陷阱：`Math.TAU` 的值是 `PI*2`（v3 是 `PI/2`），`Math.PI2` 已被删除。本项目一律用 `Math.PI * 2` 字面量，禁用 `Math.TAU` 与 `Math.PI2`。**
- **Phaser 4 陷阱：`roundPixels` 默认值已从 `true` 翻转为 `false`，且默认画布尺寸改为 1024×768。本项目显式设置 `width`/`height` 与 `roundPixels: true`。**

## Review Focus

以下是 spec 隐含、但容易在实现中被打穿的五类输入/失效模式。每条都已落到具体任务的测试里。

| # | 输入 / 条件 | 合理预期 | 承接任务 |
|---|---|---|---|
| 1 | 浏览器标签页被切到后台再切回，`delta` 突然变成数千毫秒 | 累加器被钳制，游戏跳帧追上而不是陷入无限循环卡死 | Task 10 |
| 2 | 某一方单位数组为空（开局无兵、或全部阵亡） | 六个系统全部不抛异常，tick 正常推进 | Task 7 |
| 3 | PRNG 状态经序列化再反序列化 | 后续随机序列与原状态完全一致 | Task 4 |
| 4 | 数据表里一个极小的秒值（如 0.01s） | 转成 tick 后为 0，不会产生「0 tick 冷却」导致的除零或死循环 | Task 5 |
| 5 | 单位 X 落在 `[0, worldWidth]` 之外 | sim 永不产出非有限值或越界坐标，渲染层不会拿到 NaN | Task 7 |

### Task 4: 种子 PRNG

**Files:**
- Create: `src/sim/rng.ts`
- Test: `src/sim/rng.test.ts`

**Interfaces:**
- Consumes: 无
- Produces:
  - `nextRandom(state: number): { value: number; state: number }` —— `value ∈ [0, 1)`
  - `randomInt(state: number, maxExclusive: number): { value: number; state: number }` —— `value ∈ [0, maxExclusive)`
  - `pickWeighted<T>(state: number, entries: readonly { item: T; weight: number }[]): { value: T; state: number }`

**设计要点：** PRNG 是**纯函数**——状态显式传入、显式传出，不藏任何模块级可变变量。这样 `World` 才能把 `rngState` 一起序列化，spec §5.2 要求的「回放」才成立。

- [ ] **Step 3: 写实现**

创建 `src/sim/rng.ts`：

```ts
/**
 * Seeded, deterministic pseudo-random number generator (mulberry32).
 *
 * Every function here is PURE: the generator state is passed in and returned
 * out. There is no module-level mutable state, so a World can serialize its
 * rngState and resume the exact same sequence later (spec §5.2).
 *
 * Never use Math.random() in src/sim — ESLint blocks it.
 */

const UINT32 = 4294967296;

/** Advances the generator one step. Returns a value in [0, 1) and the new state. */
export function nextRandom(state: number): { value: number; state: number } {
  const next = (state + 0x6d2b79f5) | 0;
  let t = next;
  t = Math.imul(t ^ (t >>> 15), 1 | t);
  t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
  const value = ((t ^ (t >>> 14)) >>> 0) / UINT32;
  return { value, state: next };
}

/** Returns an integer in [0, maxExclusive). maxExclusive <= 1 always yields 0. */
export function randomInt(
  state: number,
  maxExclusive: number,
): { value: number; state: number } {
  const r = nextRandom(state);
  if (maxExclusive <= 1) return { value: 0, state: r.state };
  return { value: Math.floor(r.value * maxExclusive), state: r.state };
}

export interface WeightedEntry<T> {
  item: T;
  weight: number;
}

/**
 * Picks one entry with probability proportional to its weight.
 * Entries with weight <= 0 are never picked.
 * Falls back to the last entry if every weight is non-positive.
 */
export function pickWeighted<T>(
  state: number,
  entries: readonly WeightedEntry<T>[],
): { value: T; state: number } {
  const total = entries.reduce((sum, e) => sum + Math.max(0, e.weight), 0);
  const r = nextRandom(state);

  if (total <= 0) {
    return { value: entries[entries.length - 1].item, state: r.state };
  }

  let threshold = r.value * total;
  for (const entry of entries) {
    threshold -= Math.max(0, entry.weight);
    if (threshold < 0) return { value: entry.item, state: r.state };
  }
  return { value: entries[entries.length - 1].item, state: r.state };
}
```

```ts
 * Data tables are written in SECONDS because that is the natural unit for
```

```ts
/** Tactical posture. The only way to move units — there is no click-to-move (spec §4.2). */

  typeId: UnitTypeId;
  /** Current X in px. */
  x: number;

  stateEnteredTick: number;

  targetId: number | null;
  /** Wind-up ticks remaining. 0 means the unit may strike. Sync point for animation + sfx. */
  windupTicksLeft: number;
  /** Attack cooldown ticks remaining. */
  cooldownTicksLeft: number;
  /** Ticks left in the current gather action (miners only). */
  gatherTicksLeft: number;
  /** Gold currently carried (miners only). */
  carrying: number;
  /** Ticks left in a stun. Reserved — no producer in v1. */
  stunTicksLeft: number;
}

export interface Base {
  side: Side;
  x: number;
  hp: number;
  maxHp: number;
}

export interface Mine {
  side: Side;
  x: number;
  goldLeft: number;
}

/** Purely logical projectile. The renderer may draw a trail but sim never depends on it. */
export interface Projectile {
  id: number;
  side: Side;
  x: number;
  targetId: number;
  damage: number;
  /** Ticks until the projectile lands and resolves damage. */
  ticksToImpact: number;
}

export type Outcome = 'ongoing' | 'playerWin' | 'playerLose';

export interface World {
  tick: number;
  /** Serialised PRNG state — travels with the world so replays resume exactly (spec §5.2). */
  rngState: number;
  units: Unit[];
  nextUnitId: number;
  bases: Record<Side, Base>;
  mines: Record<Side, Mine>;
  projectiles: Projectile[];
  nextProjectileId: number;
  gold: Record<Side, number>;
  popUsed: Record<Side, number>;
  trainingQueue: Record<Side, TrainingOrder[]>;
  /** Index of the next wave to spawn (scripted levels). */
  waveIndex: number;
  /** Tick at which the next wave should spawn. */
  nextWaveTick: number;
  outcome: Outcome;
  levelId: string;
}

  typeId: UnitTypeId;
  /** Ticks remaining until the unit appears. */
  ticksLeft: number;
}

export interface WaveScript {
  /** Tick at which this wave spawns. */
  atTick: number;
  /** Units to spawn, as a list of type ids. */
  units: UnitTypeId[];
}

export interface MatchConfig {
  levelId: string;
  worldWidth: number;
  baseHp: Record<Side, number>;
  mineGold: Record<Side, number>;
  startGold: Record<Side, number>;
  startMiners: Record<Side, number>;
  popCap: Record<Side, number>;
  /** `scripted` = waves only, no economy. `economy` = full two-layer AI (spec §8.4). */
  enemyAi: 'scripted' | 'economy';
  /** Scripted wave table. Empty when enemyAi is `economy`. */
  waves: WaveScript[];
  endless: boolean;
  /** Multiplier applied to enemy HP and attack. 1 = no scaling. */
  difficultyMult: number;
}

/**
 * Input to the simulation. The ONLY way the outside world affects sim state.
 * Player commands and AI commands share this exact type, which is what makes
 * the AI fair — it is literally pressing the same buttons (spec §9.1).
 */

  | { kind: 'train'; side: Side; typeId: UnitTypeId }
```

```ts
/**
 * Builds the initial World from a MatchConfig and a seed.
 *
 * This is the ONLY place where data-table seconds are converted to integer
 * ticks. Downstream code can assume every duration field is already an
 * integer tick count (spec §5.1).
 *
 * M1 creates no units from data tables, so no conversion happens yet; the
 * toTicks import arrives with M2's training queue.
 */

import { BASE_X, MINE_X } from '../data/levels';
import { SPAWN_OFFSET, UNITS } from '../data/units';
import type { MatchConfig, Side, Unit, World } from './types';

const SIDES: readonly Side[] = ['player', 'enemy'];

export function createWorld(config: MatchConfig, seed: number): World {
  const units: Unit[] = [];
  let nextUnitId = 1;

  for (const side of SIDES) {
    const count = config.startMiners[side] ?? 0;
    for (let i = 0; i < count; i++) {
      units.push(
        spawnInitialUnit('miner', side, i, config, nextUnitId++),
      );
    }
  }

  const popUsed = { player: 0, enemy: 0 } as Record<Side, number>;
  for (const unit of units) {
    popUsed[unit.side] += UNITS[unit.typeId].popCost;
  }

  return {
    tick: 0,
    rngState: seed,
    units,
    nextUnitId,
    bases: {
      player: { side: 'player', x: BASE_X.player, hp: config.baseHp.player, maxHp: config.baseHp.player },
      enemy: { side: 'enemy', x: BASE_X.enemy, hp: config.baseHp.enemy, maxHp: config.baseHp.enemy },
    },
    mines: {
      player: { side: 'player', x: MINE_X.player, goldLeft: config.mineGold.player },
      enemy: { side: 'enemy', x: MINE_X.enemy, goldLeft: config.mineGold.enemy },
    },
    projectiles: [],
    nextProjectileId: 1,
    gold: { player: config.startGold.player, enemy: config.startGold.enemy },
    popUsed,
    trainingQueue: { player: [], enemy: [] },
    waveIndex: 0,
    nextWaveTick: config.waves.length > 0 ? config.waves[0].atTick : Number.MAX_SAFE_INTEGER,
    outcome: 'ongoing',
    levelId: config.levelId,
  };
}

/**
 * Places a starting unit just inside its own base, spread along X so the
 * initial stack does not violate the separation constraint on tick 1.
 */
function spawnInitialUnit(
  typeId: Unit['typeId'],
  side: Side,
  index: number,
  config: MatchConfig,
  id: number,
): Unit {
  const def = UNITS[typeId];
  const dir = side === 'player' ? 1 : -1;
  const rawX = BASE_X[side] + dir * (SPAWN_OFFSET + index * def.bodyRadius * 2.5);
  const x = clamp(rawX, 0, config.worldWidth);

  return {
    id,
    side,
    typeId,
    x,
    prevX: x,
    hp: def.maxHp,
    state: 'idle',
    stateEnteredTick: 0,
    stance: 'hold',
    targetId: null,
    windupTicksLeft: 0,
    cooldownTicksLeft: 0,
    gatherTicksLeft: 0,
    carrying: 0,
    stunTicksLeft: 0,
  };
}

function clamp(value: number, min: number, max: number): number {
  return Math.min(Math.max(value, min), max);
}
```

- [ ] **Step 4: 写 `src/sim/tick.ts`**

```ts
/**
 * The six-step tick orchestrator (spec §6.1).
 *
 * ORDER IS LOAD-BEARING AND MUST NOT CHANGE:
 *   economy -> commands -> ai -> movement -> combat -> cleanup
 *
 * Two constraints in particular:
 *   - movement before combat, or range checks use last tick's positions and
 *     every melee engagement is off by one tick.
 *   - combat before cleanup, or a unit marked dead this tick still lands a hit
 *     (corpse double-kill).
 *
 * Changing this order changes simulation results for the same seed, which
 * invalidates replay and batch balance runs. tick.test.ts asserts the order.
 *
 * Never use Math.random / Date.now / performance.now in here or in systems/.
 */

import type { Command, World } from './types';
import { economySystem } from './systems/economy';
import { commandsSystem } from './systems/commands';
import { aiSystem } from './systems/ai';
import { movementSystem } from './systems/movement';
import { combatSystem } from './systems/combat';
import { cleanupSystem } from './systems/cleanup';

export interface TickContext {
  world: World;
  commands: Command[];
}

export type TickSystem = (ctx: TickContext) => void;

/**
 * The fixed system order. `step` iterates this array, so the declaration here
 * and the execution order can never drift apart.
 */
export const TICK_SYSTEMS: readonly TickSystem[] = [
  economySystem,
  commandsSystem,
  aiSystem,
  movementSystem,
  combatSystem,
  cleanupSystem,
];

/** Advances the world by exactly one logic tick. */
export function step(world: World, commands: Command[]): void {
  const ctx: TickContext = { world, commands };
  for (const system of TICK_SYSTEMS) {
    system(ctx);
  }
  world.tick += 1;
}
```

> **注意**：`systems/*.ts` 从 `../tick` import `TickContext`，而 `tick.ts` 从 `./systems/*` import 函数——这是一个类型层面的循环引用。TypeScript 能处理（`import type` 在编译后被擦除），但**必须确保 systems 里用的是 `import type`**，否则会产生运行时循环依赖。上面的代码已全部使用 `import type`。

```ts
import Phaser from 'phaser';
import { WORLD_WIDTH } from '../../data/constants';
import { DEFAULT_MATCH } from '../../data/levels';
import { createWorld } from '../../sim/createWorld';
import type { World } from '../../sim/types';

/** Ground sits this fraction down the viewport, leaving the lower third empty (spec §7.2). */
const GROUND_FRACTION = 2 / 3;

/**
 * Owns the Phaser side of the game: camera, drawing, and the fixed-timestep
 * driver. Reads sim state every frame and NEVER writes to it (spec §3.1).
 */
export class BattleScene extends Phaser.Scene {
  private world!: World;
  private groundLine!: Phaser.GameObjects.Graphics;
  private groundY = 0;

  constructor() {
    super({ key: 'Battle' });
  }

  create(): void {
    this.world = createWorld(DEFAULT_MATCH, 20260925);

    this.groundLine = this.add.graphics();

    this.layout();
    this.scale.on('resize', () => this.layout());
  }

  /**
   * Recomputes viewport-derived geometry. Called on create and on every
   * resize. The sim is deliberately unaware of any of this.
   */
  private layout(): void {
    const { width, height } = this.scale;
    this.groundY = Math.round(height * GROUND_FRACTION);

    this.cameras.main.setBounds(0, 0, WORLD_WIDTH, height);
    this.cameras.main.setScroll(0, 0);

    this.drawGround();
  }

  /** Draws the ground line and the base markers. Camera-agnostic: world coords only. */
  private drawGround(): void {
    this.groundLine.clear();

    // Sub-surface fill so the ground reads as solid.
    this.groundLine.fillStyle(0x2b3038, 1);
    this.groundLine.fillRect(0, this.groundY, WORLD_WIDTH, this.scale.height - this.groundY);

    // The ground line itself.
    this.groundLine.lineStyle(2, 0x5b6472, 1);
    this.groundLine.lineBetween(0, this.groundY, WORLD_WIDTH, this.groundY);

    // Base markers, so camera movement is legible before units exist.
    this.drawBaseMarker('player', 0x3f7fd0);
    this.drawBaseMarker('enemy', 0xd05a3f);
  }

  private drawBaseMarker(side: 'player' | 'enemy', color: number): void {
    const base = this.world.bases[side];
    this.groundLine.fillStyle(color, 0.6);
    this.groundLine.fillRect(base.x - 20, this.groundY - 60, 40, 60);
  }
}
```

```ts
import type { UnitState } from '../../sim/types';

/** Joint angles in radians. 0 points down (+Y); positive rotates clockwise on screen. */
export interface Pose {
  torso: number;
  armFront: number;
  armBack: number;
  legFront: number;
  legBack: number;
  /** Weapon angle relative to the front arm. */
  weapon: number;
}

export const IDLE_POSE: Pose = {
  torso: 0,
  armFront: -0.25,
  armBack: 0.25,
  legFront: -0.12,
  legBack: 0.12,
  weapon: -0.6,
};

/**
 * M1 renders every state as the idle pose. M2 replaces the entries with real
 * keyframe sets driven by the `phase` argument (0..1 through the state).
 */
export const POSE_BY_STATE: Record<UnitState, Pose> = {
  idle: IDLE_POSE,
  move: IDLE_POSE,
  gather: IDLE_POSE,
  attack: IDLE_POSE,
  stunned: IDLE_POSE,
  dead: IDLE_POSE,
};

/**
 * Returns the pose for a unit's state at a given phase through that state.
 * `phase` is 0..1 and is ignored in M1.
 */
export function poseFor(state: UnitState, _phase: number): Pose {
  return POSE_BY_STATE[state];
}
```

- [ ] **Step 3: 写 `src/render/stickman/skeleton.ts`**

```ts
import Phaser from 'phaser';
import type { UnitTypeId } from '../../data/units';
import type { UnitState } from '../../sim/types';
import { PALETTES } from './palette';
import { poseFor } from './poses';

const LIMB_THICKNESS = 4;
const TORSO_LENGTH = 22;
const HEAD_RADIUS = 6;
const ARM_LENGTH = 16;
const LEG_LENGTH = 18;
const WEAPON_LENGTH = 16;

/**
 * Distance from the container origin (the hip) down to the feet.
 * Position a stickman at `groundY - STICKMAN_HIP_HEIGHT` to stand it on the ground.
 */
export const STICKMAN_HIP_HEIGHT = LEG_LENGTH;

export interface Stickman {
  container: Phaser.GameObjects.Container;
  /** Applies a pose. `phase` is 0..1 through the current state. */
  apply(state: UnitState, phase: number): void;
  destroy(): void;
}

/**
 * Builds a stickman from persistent Shape objects. Limbs are never recreated —
 * animation only mutates `rotation`, so there is no per-frame allocation
 * (spec §7.1).
 *
 * Structure (all coordinates relative to the hip at 0,0, +Y is down):
 *   hip ─┬─ legBack, legFront          (rotate at the hip)
 *        ├─ torso  (origin 0.5,1)      (extends upward)
 *        ├─ head   (above the shoulders)
 *        └─ armBack, armFront (containers at the shoulder, each holding a limb
 *           rectangle, with the front arm also holding the weapon)
 *
 * The arms are Containers rather than bare Rectangles because Phaser Shapes
 * cannot have children — the weapon must inherit the arm's rotation, which
 * requires a nested container.
 */
export function createStickman(scene: Phaser.Scene, typeId: UnitTypeId): Stickman {
  const palette = PALETTES[typeId];

  const legBack = scene.add
    .rectangle(0, 0, LEG_LENGTH, LIMB_THICKNESS, palette.limb)
    .setOrigin(0, 0.5);
  const legFront = scene.add
    .rectangle(0, 0, LEG_LENGTH, LIMB_THICKNESS, palette.limb)
    .setOrigin(0, 0.5);

  const torso = scene.add
    .rectangle(0, 0, LIMB_THICKNESS, TORSO_LENGTH, palette.limb)
    .setOrigin(0.5, 1);

  const head = scene.add.circle(0, -TORSO_LENGTH - HEAD_RADIUS + 1, HEAD_RADIUS, palette.head);

  const shoulderY = -TORSO_LENGTH + 3;

  const armBackLimb = scene.add
    .rectangle(0, 0, ARM_LENGTH, LIMB_THICKNESS, palette.limb)
    .setOrigin(0, 0.5);
  const armBack = scene.add.container(0, shoulderY, [armBackLimb]);

  const armFrontLimb = scene.add
    .rectangle(0, 0, ARM_LENGTH, LIMB_THICKNESS, palette.limb)
    .setOrigin(0, 0.5);
  const weapon = scene.add
    .rectangle(ARM_LENGTH - 2, 0, WEAPON_LENGTH, 3, palette.weapon)
    .setOrigin(0, 0.5);
  const armFront = scene.add.container(0, shoulderY, [armFrontLimb, weapon]);

  // Back-to-front draw order.
  const container = scene.add.container(0, 0, [
    armBack,
    legBack,
    legFront,
    torso,
    head,
    armFront,
  ]);

  return {
    container,
    apply(state: UnitState, phase: number): void {
      const pose = poseFor(state, phase);
      torso.setRotation(pose.torso);
      armFront.setRotation(pose.armFront);
      armBack.setRotation(pose.armBack);
      legFront.setRotation(pose.legFront);
      legBack.setRotation(pose.legBack);
      weapon.setRotation(pose.weapon);
    },
    destroy(): void {
      container.destroy(true);
    },
  };
}
```

### Task 10: 固定时间步进与插值

这是 M1 的收口任务：把 `step()` 接进渲染循环，加上累加器钳制与插值，并显示 tick 计数以证明逻辑帧率与渲染帧率确实解耦。

**Files:**
- Modify: `src/render/scenes/BattleScene.ts`
- Create: `src/render/timestep.ts`
- Test: `src/render/timestep.test.ts`

**Interfaces:**
- Consumes: `sim/tick.ts`, `data/constants.ts`
- Produces:
  - `STEP_MS = 1000 / TICKS_PER_SEC`
  - `MAX_ACCUMULATOR_MS`
  - `class FixedTimestep`，含 `advance(deltaMs: number): number`（返回本帧应执行的 tick 数）与 `get alpha(): number`

**设计要点（Review Focus #1）：** 标签页切到后台再切回时，`delta` 会突然变成数千毫秒。若不钳制累加器，`while` 循环会尝试补跑上百个 tick，一帧耗时暴涨，导致下一帧 `delta` 更大，最终卡死（"spiral of death"）。钳制累加器上限是标准解法。

**为什么把累加器抽成独立类：** 它是纯计算，可以脱离 Phaser 单测——`delta` 尖峰这一失效模式只有在测试里才能被可靠地覆盖。

```ts
/**
 * Fixed-timestep accumulator for the render loop (spec §3.3).
 *
 * Kept free of Phaser so the tricky part — surviving a huge `delta` after the
 * tab was backgrounded — is unit-testable.
 *
 * Without the cap, a 60s stall makes the while loop try to run 1800 ticks in
 * one frame; that frame takes far longer than a frame, so the next delta is
 * even bigger, and the game never recovers ("spiral of death").
 */

import { TICKS_PER_SEC } from '../data/constants';

/** Duration of one logic tick in milliseconds. */
export const STEP_MS = 1000 / TICKS_PER_SEC;

/**
 * Upper bound on unspent time. Beyond this we drop the excess rather than
 * trying to catch up. 250ms = at most 7 catch-up ticks in one frame.
 */
export const MAX_ACCUMULATOR_MS = 250;

export class FixedTimestep {
  private accumulator = 0;

  /**
   * Feeds one render frame's elapsed time and returns how many logic ticks
   * should run this frame.
   */
  advance(deltaMs: number): number {
    if (deltaMs > 0) {
      this.accumulator += deltaMs;
    }
    if (this.accumulator > MAX_ACCUMULATOR_MS) {
      this.accumulator = MAX_ACCUMULATOR_MS;
    }

    const ticks = Math.floor(this.accumulator / STEP_MS);
    this.accumulator -= ticks * STEP_MS;
    return ticks;
  }

  /** Interpolation factor in [0, 1) between the previous and current tick. */
  get alpha(): number {
    const alpha = this.accumulator / STEP_MS;
    if (alpha < 0) return 0;
    if (alpha >= 1) return 0.999999;
    return alpha;
  }
}
```
